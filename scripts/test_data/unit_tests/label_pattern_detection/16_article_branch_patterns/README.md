# 16_article_branch_patterns: 枝番付き第○ラベルパターン

## 目的

「第一の二」（2分割）や「第一の一の二」「第十三の二の二」（3分割・多段）のような、
「第○」＋「の」＋数字の枝番付きラベルが、枝番なしの「第○」ラベルと
**同一の種別（同一階層）**としてマークアップされることを検証する。

実例: 告示 XML（H18厚労省告示107号 掲示事項等）の
「第一の二」「第一の一の二」「第十の二」「第十三の二の二」。

## 検証内容

1. 「第一」「第一の一の二」「第一の二」「第十三の二の二」が同一階層（Item）に変換される
2. 「第○」配下の漢数字「一」「二」は従来どおり下位階層（Subitem1）に変換される
3. Num 属性がタイトル由来のコーパス準拠枝番形式で採番される
   （「第一の二」→ Num="1_2"、「第一の一の二」→ Num="1_1_2"、「第十三の二の二」→ Num="13_2_2"）

## 関連設定

- `scripts/config/label_config.json` の `article_boundary` パターン
  （`(?:[のノ]…)*` による枝番対応拡張。数字種別はラベル内で統一されている場合のみ）
- `scripts/convert_article_focused.py` の `article_boundary_pattern`（同様の拡張）
- `scripts/utils/renumber_utils.py` の `title_to_num`（枝番形式 Num の導出）
