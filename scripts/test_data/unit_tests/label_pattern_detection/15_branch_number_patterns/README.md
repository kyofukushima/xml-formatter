# 15_branch_number_patterns: 枝番付き数字ラベルパターン

## 目的

「一の二」「１の１」「1の2」のような、数字＋「の」＋数字の枝番付きラベルが、
枝番なしの同種ラベル（「一」「１」「1」）と**同一の種別（同一階層）**として
マークアップされることを検証する。

実例: 告示 XML（H21厚労省告示509号 等）の「十の二」「十三の二」〜「十三の四」。

## 検証内容

1. 漢数字「一」「一の二」「二」「十三の四」が同一階層（Item）に変換される
2. 全角数字「１」「１の１」「２」が同一階層（Subitem1）に変換される
3. 半角数字「1」「1の2」が同一階層（Subitem2)に変換される
4. Num 属性がタイトル由来のコーパス準拠枝番形式で採番される
   （「一の二」→ Num="1_2"、「十三の四」→ Num="13_4"）

## 関連設定

- `scripts/config/label_config.json` の `kanji_number` / `fullwidth_number` / `halfwidth_number`
  パターン（`(?:[のノ]…)*` による枝番対応拡張）
- `scripts/utils/renumber_utils.py` の `title_to_num`（枝番形式 Num の導出）
