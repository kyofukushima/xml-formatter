# 21_paren_branch_number_patterns: 枝番付き括弧数字ラベルパターン

## 目的

「（１）の２」「（２）の２の２」「(1)の2」「（一）の二」のような、
括弧数字＋「の」＋数字の枝番付きラベルが、枝番なしの同種ラベル
（「（１）」「(1)」「（一）」）と**同一の種別（同一階層）**として
マークアップされることを検証する。

実例: 告示 XML（H20厚労省告示63号 → R07告示173号、`sample/サンプル（1012）`）の
「（１）の２」「（２）の２」「（２）の２の２」「（１１）の３」等。

## 検証内容

1. 括弧全角数字「（１）」「（１）の２」「（２）」「（２）の２の２」が同一階層（Item）に変換される
2. 括弧漢数字「（一）」「（一）の二」が同一階層（Subitem1）に変換される
3. 括弧半角数字「(1)」「(1)の2」が同一階層（Subitem2）に変換される
4. Num 属性は括弧の中の数値から枝番形式で採番される
   （「（１）の２」→ Num="1_2"、「（２）」→ Num="2"、「（２）の２の２」→ Num="2_2_2"）。
   なおコーパス（元XML）側ではこれらは連番（Num="2" 等）になっている

## 関連設定

- `scripts/config/label_config.json` の `paren_fullwidth_number` / `paren_halfwidth_number` /
  `paren_kanji_number` パターン（`(?:[のノ]…)*` による枝番対応拡張）
- `scripts/utils/label_utils.py` の `split_label_and_content`（括弧数字の枝番付き分離）
- 数字ラベルの枝番対応は `15_branch_number_patterns` を参照
