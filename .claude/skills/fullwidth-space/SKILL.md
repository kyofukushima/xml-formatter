# 文頭全角スペース補填（一括実行）

引数: `$ARGUMENTS`（入力パスとオプション。省略時はユーザーに入力パスを確認する）

## 手順

1. 入力パス（フォルダ / ZIP / XMLファイル、複数可）を確認する。存在しなければユーザーに聞く。
2. 出力先が指定されていなければ既定値（`<入力名>_space` フォルダ、ZIP入力なら `<入力名>_space.zip`）を使う。既定の出力先が既に存在する場合は上書きになるので、実行前にユーザーへ一言確認する。
3. 次のコマンドで実行する（必ず venv の python を使う）:

```bash
venv/bin/python scripts/batch_fullwidth_space.py <入力...> [-o <出力先>] [オプション]
```

オプション（Webアプリのチェックボックスと同じ。ユーザーが明示しない限り付けない）:

| オプション | 意味 |
|---|---|
| `--include-list` | List内のSentenceも対象にする |
| `--exclude-paren` | 「（」で始まるSentenceは対象外にする |
| `--include-vardef` | 変数定義行（「Ｅ：…」等の短い記号列）も対象にする |
| `--keep-names` | 出力ファイル名を元のままにする（既定は `<元の名前>_space.xml`） |
| `--csv <path>` | ファイルごとの結果一覧をCSVに保存する |
| `-o <path>` | 出力先。`.zip` を指定するとZIPで出力 |

4. 終了コードと標準出力の「処理統計」を確認する。終了コード 2 は一部ファイルが解析エラー（出力に含まれない）。
5. ユーザーには次を短く報告する: 出力先、処理ファイル数、補填実施箇所数、除外数、エラーのあったファイルとその理由。

## 注意

- 既に全角スペースで始まるSentenceには挿入しないため、再実行しても安全（冪等）。
- 入力XMLの整形（インデント等）は変更しない。
- 判定条件の詳細は `scripts/postprocess_fullwidth_space.py` の冒頭コメントを参照。
